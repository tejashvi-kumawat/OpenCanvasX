# Contributing

Thank you for contributing to OpenCanvasX.

1. Read [docs/agent-guide.md](docs/agent-guide.md) and [docs/checklist.md](docs/checklist.md).
2. Follow [docs/contributing-conventions.md](docs/contributing-conventions.md) for branches and commits.
3. Run `./scripts/bootstrap.sh`, then `dart run melos analyze` and `dart run melos test` before opening a PR.
4. Do not commit secrets, API keys, or proprietary Canva-derived content.
5. New assets require license metadata per [docs/product/legal-content-rules.md](docs/product/legal-content-rules.md).

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) and [SECURITY.md](SECURITY.md).
