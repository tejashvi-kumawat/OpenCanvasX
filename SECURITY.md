# Security policy

## Reporting a vulnerability

Please report security issues privately (GitHub Security Advisories or maintainer email once published). Do not open public issues for exploitable vulnerabilities.

## Scope

Collaboration crypto, invitation handling, plugin sandbox, and untrusted file import (SVG, PDF, templates) are in scope once implemented.

## Expectations

- We do not claim "perfect security"; see [docs/security/security-promises.md](docs/security/security-promises.md).
- Professional review is planned before high-assurance collaboration claims.

## Safe harbor

We appreciate responsible disclosure and will acknowledge reporters when fixes ship.
