# ADR-0001: Project license Apache-2.0

- **Status:** Accepted
- **Date:** 2026-10-02

## Context

We need a permissive license compatible with Flutter, Rust, FFmpeg, and typical OSS dependencies.

## Decision

Use **Apache-2.0** for the application and first-party packages. Record third-party obligations in `THIRD_PARTY_NOTICES`.

## Consequences

Patent grant and NOTICE requirements; per-dependency audit still required before bundling.
