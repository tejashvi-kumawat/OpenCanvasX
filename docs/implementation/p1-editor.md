Engineering log for the first usable editor. Normative design: [ux-spec.md](../product/ux-spec.md), [overview.md](../architecture/overview.md), [document-model.md](../architecture/document-model.md), [rendering-architecture.md](../architecture/rendering-architecture.md). ## What a user can do

- **First run (P1.1.7, part of P1.10.6):** welcome screen with the privacy promise; one click uses `Documents/OpenCanvasX` (created if missing) or picks any folder.
- **Home:** create from size presets or a custom size (P1.2.3), search and reopen designs from live thumbnails, change the projects folder, switch light/dark/system theme (P1.10.3).
- **Editor layout (P1.10.1):** toolbar (main menu with File/Edit/View/Insert/Arrange, tools Move · Shapes ▾ · Lines ▾ · Text · Hand, title + save state, undo/redo, zoom, theme), left sidebar (Layers tab: Pages + Layers; Elements tab: Text, Shapes, Lines), canvas, inspector (P1.10.2) in the order Alignment, Layout, Text, Appearance, Fill, Stroke.
- **Canvas (P1.2.1, P1.2.2, P1.2.5):** pages stacked vertically; wheel/trackpad pan, Ctrl+wheel zoom at cursor, middle-button or Space+drag pan, zoom slider and menu, fit page (Ctrl+0), 100 % (Ctrl+1).
- **Shapes (P1.3.1, P1.3.2):** rectangle, rounded rectangle, ellipse, polygon, star, line, arrow — draw with a tool (drag; Shift = square / 45°), click or drag from Elements, or the Insert menu. Tool shortcuts V, H, R, O, L, Shift+L, T.
- **Text (P1.5.1–P1.5.3):** heading/subheading/body from Elements or the Text tool (click to place); double-click or Enter edits inline; font, weight, size, italic, alignment, auto width / auto height / fixed, line height, letter spacing. Dragging a side handle of an auto-width text switches it to auto height.
- **Strokes (P1.3.5):** colour, weight, solid/dashed/dotted; opacity and blend mode in Appearance.
- **Workspaces (P2.5.3):** projects are folders in the projects root marked with `.opencanvasx-project`; Home's sidebar lists them (+ to create). Choosing one filters designs and new designs/templates are created in it. Each design card has Rename, Duplicate, Move to project / out of project and Move to trash (`<root>/.trash`, recoverable).
- **Templates (P2.2):** 24 original templates (social posts, stories, thumbnails, decks, poster, menu, flyer, business cards, resume, certificate, invitations, app screens and landing page boards). Home shows a gallery (search, categories) that creates a design; the editor's Design panel adds a template as new pages, or as frames on a board.
- **Home:** hero with search, quick kinds (free canvas, website & app, social, story, presentation, video, print, custom), templates, blank sizes, recent designs; sidebar Home · Templates · Your designs.
- **Layout (P1.10.1, design-system.md §5):** slim top bar with Export; 72 px content rail (Design, Elements, Text, Uploads, Layers, Pages) opening a 300 px panel; floating tool bar on the canvas.
- **Elements (P2.1.2):** shapes, lines, frame sizes, icons (Lucide, Tabler, Phosphor — pack and style filters) and stickers (Twemoji by category) with search; click to add or drag onto the canvas. Monochrome icons take the object's fill as their colour.
- **Uploads (P1.6.1, P1.6.2):** PNG, JPEG, WebP, GIF, BMP, SVG via the file dialog; validated by content (`asset_engine.checkMedia`), stored once per SHA-256 hash in the design, reusable from the panel. Placed images show their source and licence in the inspector (P2.1.4).
- **Export (P1.9):** Export button, File → Export…, Ctrl+Shift+E. PNG (0.5–4×, transparent option), JPG (quality), SVG (vector shapes/paths/frames with clip paths, text as text with the canvas's line breaks, images embedded, icon colour baked in), PDF (one file, every page or frame at its physical size; pages are rendered at 96/192/300 dpi — vector PDF is a later step). Scope: current page (on a board: each top-level frame), all pages, or the selection. Multiple files go to a chosen folder.
- **Boards and frames (ADR-0007, early P3.7.1):** "Free canvas" / "Website & app design" in the create dialog, or *Add board* in Pages, gives an unbounded board with a dot grid when zoomed in. The Frame tool (F) draws frames; its menu inserts device, social and slide sizes. Frames clip their content (toggle in the inspector's Frame section, which also changes the size), show their name above them (click to select, drag to move), and take in anything drawn, inserted or dropped on them; dragging out releases it. Ctrl+Alt+G frames the selection; Ungroup removes a frame. Fit (Ctrl+0) on a board fits its content.
- **Assets and covers (P1.6.5):** imported media are stored once per SHA-256 in the design (`assets/sha256/<hex>`, verified on open). Every save also renders the first page (or a board's first frame), images included, to a PNG of at most 480 px and stores it as `meta/thumbnails/cover.png`; the home screen lists designs by reading only `document.json` and that cover (`readProjectFile(readAssets: false)`), so it no longer decodes every image of every design and photos show in the previews. Covers are a cache: only PNG data under 2 MB is accepted, and older files without one are drawn live.
- **Crop (P1.6.3):** double-click an image (or Inspector → Crop) to enter crop mode: the whole image shows dimmed around the box, handles crop instead of resize (edges stop at the image), and dragging inside moves the image under the crop. Esc, Enter or clicking elsewhere finishes. Inspector presets crop to 1:1, 4:5, 3:2, 16:9 or 9:16 within the current box; Reset crop shows the whole image again. Crops are non-destructive (`ImagePayload.crop`), rotate and flip with the image, and export to PNG/JPEG/PDF/SVG/HTML. Resize, rotate and flip use the normal handles.
- **Masks and image frames (P1.6.4, P3.1.4):** Ctrl+Alt+M (Use as mask) groups the selection and clips it to the bottom-most layer's shape. Elements → Image frames (square, rounded, circle, arch, blob, heart, star, hexagon) add empty frames; uploading, clicking an upload or dropping an icon/sticker on a frame fills it (cover fit, replacing the previous photo); double-click the photo to reposition it.
- **Image adjustments (P3.3):** Adjust section for raster images: looks (Mono, Noir, Sepia, Vivid, Fade, Warm, Cool, Dream) and sliders for brightness, contrast, saturation, exposure, temperature, tint, hue, sepia and blur — previewed live, one undo step, non-destructive (stored as values; drawn with a colour matrix and blur; SVG export uses feColorMatrix/feGaussianBlur).
- **UI kit:** the official template repository includes `ui-kit`, a board of 16 original main components (buttons, badge, avatar, toggle, checkbox, text field, search bar, alert, product/pricing/testimonial cards, desktop navbar, phone status bar, mobile tab bar). Elements → UI kit previews them; the first use copies the component (with its icons) into the design as a main component, later uses add instances.
- **Components (Figma-style):** Ctrl+Alt+K turns a frame or the selection into a main component (unfilled frame, shown with a component icon in Layers). Instances (Elements → Components in this design, or the inspector's Create instance) draw the main component live, scaled to their box, so edits to the main update every instance; Ctrl+Alt+B detaches into an editable frame; Go to main selects the component. A deleted main shows a dashed red placeholder. Overrides and variants are next.
- **Website export (early P3.9.2):** Export → Website writes one HTML file per board frame (or per page) with the design as inline SVG scaled to the window (text stays selectable), `index.html` first; prototype links become real links (hotspots), pages get previous/next links. Works offline, no scripts.
- **Prototyping and present mode:** on a board, any object can link to a frame (inspector → Prototype: target frame and transition — instant, dissolve, slide left/right/up); links of the selection draw as accent arrows on the canvas and are removed with their objects. Present (top bar, F5) plays the board's frames as a clickable prototype (← goes back), or the design's pages as a slideshow (click, →, Space, PageDown; ← PageUp; Home; Esc leaves).
- **Colour (P1.7):** every colour swatch opens a picker: saturation/brightness square, hue and opacity sliders, HEX / RGB / HSL / HSV fields, an eyedropper that samples the canvas (next click), default swatches, colours used in this design and "My colours" (saved in the app index). Dragging previews live and commits one undo step. Fill can be solid, linear (angle) or radial gradient with draggable stops (click the bar to add, select to recolour or remove). Text shows its WCAG contrast against the page or enclosing frame (AAA / AA / large text only / too low).
- **Vector drawing (P2.6):** Pen (P): click to place points, drag to pull out smooth Bézier handles, click the first point to close, double-click, Enter or Escape to finish an open path; points snap. Pencil (Shift+P): freehand strokes simplified (Ramer–Douglas–Peucker) and smoothed into curves. Double-click a path to edit nodes: drag points or handles (opposite handle mirrors; Alt breaks the pair), Delete removes the selected point, Escape leaves. Paths store a view box so resizing scales their curves; strokes keep their width.
- **Rulers, guides, grid (P1.2.4):** View → Rulers (Shift+R) shows rulers along the top and left of the canvas in the active page's unit, with 1/2/5 × 10ⁿ steps chosen for at least 60 px between labels and the selection's extent highlighted. Dragging from a ruler places a guide (`DesignPage.guides`, one undo step "Add guide"); guides are red lines across the canvas that can be dragged to move ("Move guide") or dropped back on the ruler or outside the canvas to remove ("Remove guide"). View → Guides (Ctrl+;) hides and shows them; View → Clear guides removes the page's guides. View → Grid (Ctrl+') draws a grid on fixed pages (8 px, 6 pt, 5 mm, 0.5 cm or ¼ in) when it is at least 6 px apart on screen. Which aids are shown is remembered (`canvas.aids` setting).
- **History and versions (P1.8.2, P1.8.3):** the History rail tab lists every step since the design was opened ("Opened", then each action's label; undone steps greyed). Clicking a step undoes or redoes to it in one go (`EditorController.stepHistory`). Save version stores a named copy of the design (with its assets) in `<design folder>/.ocx/snapshots/<design name>/` as `<time>.opencanvasx` plus `<time>.json` with the label; hidden folders are never listed as designs. Restore replaces the design with the version as one undoable step ("Restore …"); versions can be deleted from the list.
- **Onboarding (P1.10.6):** the first-run page asks for an optional name (saved as `profile.name`, used as `DocumentMetadata.author` for new designs and designs made from templates, editable from the home sidebar), where designs are saved (Documents › OpenCanvasX or another folder), and explains the privacy model: works offline, no account/uploads/tracking, open file format, and only features the user turns on (online template sources, an AI provider) ever go online, always asked first. A cryptographic identity for collaboration arrives with P4.1.
- **Command palette (P1.10.5):** Ctrl+K opens a palette of ~80 commands (tools, insert, pages, edit, arrange/align/distribute/flip, view toggles, zoom, theme, every rail panel, save/versions/export/present, AI settings, keyboard shortcuts). Fuzzy matching (`fuzzyScore`) prefers word starts and consecutive letters and also searches keywords (e.g. "remove" finds Delete). Arrow keys move, Enter runs, Esc closes; unavailable commands are greyed.
- **Keyboard shortcuts (P1.10.4):** Menu → Keyboard shortcuts… (or the palette) lists every shortcut. 29 core shortcuts (`ShortcutId`) can be rebound by clicking and pressing new keys; a key already in use is refused with the name of its owner, and keys without Ctrl/Alt/Shift (except F-keys) are refused so typing and tool keys keep working. Changes are saved in the `shortcuts` setting as `ctrl+shift+<key id>` and apply immediately to bindings, menus and the palette; Reset all restores the defaults. Tool keys, Delete, Enter, Esc, arrows and Space stay fixed.
- **Character formatting (P1.5.4):** while editing a text, selecting characters turns the Text section into "Text · selected characters": font, weight, size, italic, underline, strikethrough and colour apply to those characters only (`TextPayload.runs`); Ctrl+B/I/U and Ctrl+Shift+X toggle bold/italic/underline/strikethrough for the selection (on unless every character already has it). Runs are painted live in the editor and follow typing: typed characters take the style of the one before (typing after a bold word stays bold), deleted ones drop out. With no selection, or with the box selected instead of edited, the same controls and shortcuts format the whole box. All changes while editing are one undo step ("Edit text"); editing ends with Esc or a click on the canvas, not when a menu, dialog or inspector field takes focus. Exports keep the formatting: PNG/JPG/WebP/image-PDF through the renderer; SVG, HTML and vector PDF place each styled piece at its laid-out position (`textSegments`), embedding fonts for every run style.
- **Fonts (P1.5.5, P1.5.6):** the font field opens a searchable picker showing every name in its own typeface: the 20 bundled OFL families first, then the fonts installed on this computer. Installed families are found by reading only the `name` table of each `.ttf/.otf/.ttc/.otc` in the system and user font folders (`asset_engine/font_names.dart`, typographic family preferred) in a background isolate; the list is cached in the `fonts.system` setting and refreshed quietly on each launch (a full Windows scan takes a few seconds). If a design uses a font that is neither bundled nor installed, the inspector says so; Flutter substitutes a similar system font for display and export. `fonts.json` in each file lists the families its text uses. A package test refuses any bundled font without an allowed licence (OFL-1.1, Apache-2.0, UFL-1.0), its licence text, a source, matching SHA-256 hashes and no stray files.
- **Snapping (P1.4.4):** moving snaps the selection's edges and centres to the page (fixed pages), other visible objects and enclosing frames within 6 screen pixels; resize handles and drawn shapes snap their edges the same way. Accent guide lines with end ticks show what snapped. Hold Alt to place freely. Ruler guides and the grid (when shown) are snap targets too.
- **Distribute (P1.4.3):** equal spacing of 3+ elements horizontally or vertically.
- **Groups (P1.3.6):** Ctrl+G groups two or more siblings (the group box fits their bounds and takes the topmost member's stacking slot); Ctrl+Shift+G ungroups, folding the group's rotation, scale, opacity and visibility into the children so nothing moves. Groups nest. A click selects the top-level object; double-click enters a group (and a further double-click goes deeper or edits text); once inside, clicks pick siblings at the same depth and the entered group stays faintly outlined; Escape goes back up one level. Moves, nudges, align and distribute work in page units through any parent rotation/scale; copies and duplicates of nested objects land on the page as top-level objects in place. Resizing a group scales its contents (aspect locked; text sizes scale too). Layers show a tree: groups expand/collapse, open automatically around the selection, children are indented; only top-level rows are drag-reordered (arrange commands reorder nested objects among their siblings). Shift/Ctrl-click in Layers adds to the selection.
- **Context menu:** right-click on the canvas for clipboard and arrange commands.
- **Selection and transforms (P1.3.3, P1.3.4):** click, Shift+click, marquee; move (Shift constrains axis), 8 resize handles (Shift keeps ratio; rotated objects keep the opposite corner fixed), rotation handle (Shift snaps 15°), flip from the inspector, arrow-key nudge.
- **Inspector:** position, size with ratio lock, rotation, opacity, fill, border, corner radius, align (P1.4.2), arrange; page name, size, presets and background when nothing is selected.
- **Clipboard (P1.3.7):** cut, copy, paste, duplicate (Ctrl+X/C/V/D).
- **Layers (P1.4.1):** reorder by dragging, rename (double-click), hide, lock. Groups are not creatable yet (P1.3.6), so the list is flat.
- **Undo/redo (P1.8.1):** every edit, Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y, labelled ("Undo move").
- **Saving:** automatic, 800 ms after the last edit, straight to the `.opencanvasx` file (atomic + verified); Ctrl+S saves immediately. Opening a design passed on the command line works (`opencanvasx.exe design.opencanvasx`).

## Testing

- `packages/design_engine`: changes, history, edits, scene queries, resize/rotate maths.
- `packages/renderer`: every object type paints; thumbnails; style resolution.
- `apps/desktop`: controller tests (`ProviderContainer`), viewport maths, and widget tests from first run through editing to going home, using an in-memory `DesignLibrary`.
- Visual review: real Windows build captured in light and dark themes.

Note: the first `dart test` / `flutter test` run downloads SQLite through the `sqlite3` build hook (hash-verified), so it needs network access once.
