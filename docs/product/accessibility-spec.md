## 50. ACCESSIBILITY

Features:
- Keyboard navigation
- Screen-reader-friendly controls where supported
- High contrast
- Large UI mode
- Reduced motion
- Focus indicators
- Color contrast checker
- Alt text
- Accessible PDF metadata
- Reading order where supported
