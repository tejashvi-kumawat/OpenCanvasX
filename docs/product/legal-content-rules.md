# Legal content rules

> **Source:** Derived from [Open_Design_Studio_Complete_Specification.md](../Open_Design_Studio_Complete_Specification.md).
> **Status:** Normative product/architecture documentation for Open Design Studio.

## 85. LEGAL CONTENT RULE

Do not copy:
- Canva templates
- Canva proprietary assets
- Canva UI artwork
- Canva source code
- Canva logos
- proprietary template metadata

Build independent implementations.

Use:
- original designs
- open-license assets
- user-generated content
- compatible third-party libraries

## 63. TEMPLATE/ASSET LICENSE SYSTEM

Every distributed asset should carry:
- license
- source
- author
- attribution requirement
- redistribution permission
- modification permission

Template repository must reject assets without known licensing metadata.

Users must be able to inspect license information.
