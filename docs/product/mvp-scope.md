# MVP scope

> **Source:** Derived from [Open_Design_Studio_Complete_Specification.md](../Open_Design_Studio_Complete_Specification.md).
> **Status:** Normative product/architecture documentation for Open Design Studio.

## 102. MVP

MVP must contain:
- Canvas
- Pages
- Layers
- Text
- Shapes
- Images
- SVG
- Basic vector editing
- Templates
- Assets
- Brand kit
- PNG export
- SVG export
- PDF export
- Local project files
- Offline operation

Collaboration MVP:
- QR
- Identity
- P2P
- E2E encryption
- Basic CRDT
- Two-user editing
- LAN
- Direct Internet where possible

AI MVP:
- BYOK provider
- Local model endpoint
- Text rewrite
- Layout generation
- Basic agent tools

## 103. POST-MVP

- Video
- Audio
- Advanced animation
- Advanced presentation
- Diagram engine
- Community repository
- Plugin marketplace/repository
- Advanced AI agents
- Team administration
- Mobile clients
